# Hockey Freunde Manager

An iPhone-first static PWA for managing a recreational hockey roster.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. Open the published HTTPS URL in Safari → Share → Add to Home Screen.

## Data
Roster, chemistry and game history are stored locally in this browser on this device. Use Export backup regularly. Import a JSON backup to restore it.
